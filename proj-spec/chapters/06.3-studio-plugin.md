# 6.3 studio-plugin

> **Spec chapter:** Roblox Studio plugin that owns the DataModel side of the session.
> **Parent:** [6. Components](06-components.md)
> **Index:** [README.md](../README.md)

**Package:** `studio-plugin/`  
**Files:** `src/` Luau plugin scripts

The plugin runs only inside Roblox Studio (Plugin security). It MUST NOT attempt to read the Windows filesystem itself. The packaged host MUST build a DataModel + ScriptEditorService adapter from `game` when a studio handle is not injected (tests may inject a fake tree).

## Construction / configuration

| Parameter | Default | Notes |
|-----------|---------|-------|
| rbx-sync host | `127.0.0.1` | User-visible loopback only (`127.0.0.1` or `::1`). Default IPv4. LAN addresses MUST be rejected in the widget. |
| rbx-sync port | `29850` | Editable in the plugin widget |
| Token | empty | User pastes `accessToken` from the rbx-sync terminal |
| Toolbar name | `rbx-sync` | `plugin:CreateToolbar` |
| Widget | Dockable | Connect / Disconnect / bootstrap choice / conflict choice. Status `TextLabel` MUST use a light `TextColor3` (near-white) so status strings stay readable on Studio’s dark plugin widget background. |

## Connect flow

The plugin MUST complete handshake and bootstrap **before** live. It MUST NOT open `/v1/events`, start `/v1/changes` polling, or start Roblox Studio mutation listeners until step 8.

1. User clicks **Connect** and submits host, port, token.
2. Plugin `GET /v1/health` (no token). If it fails, show **rbx-sync not reachable** and stop.
3. Plugin `POST /v1/session?accessToken=…` with JSON `{ "protocolVersion": 1, "pluginVersion": "<semver>" }` ([§7.1](07.1-http-api.md)).
4. On `PROTOCOL_MISMATCH` / `UNAUTHORIZED`, show the error `message` and stop.
5. Plugin walks mapped Roblox Studio roots, builds a snapshot of mapped nodes, and `POST /v1/bootstrap/compare` with `{ "nodes": [ /* that snapshot */ ] }`.
6. Branch on compare ([§6.5](06.5-sync-session.md#revision-initialization)):
   - **`equal: true`:** skip the bootstrap widget. Plugin `GET /v1/snapshot` and stores each node’s `revision`. Continue at step 8.
   - **`equal: false`:** widget requires **Disk wins**, **Roblox Studio wins**, or **Cancel**. Status MUST show **choose Disk wins, Roblox Studio wins, or Cancel** (MUST NOT remain **disconnected**). Continue at step 7. Live MUST NOT start yet.
7. Unequal bootstrap — exactly one of:
   - **Cancel:** stop immediately. No `POST /v1/bootstrap/apply`. No disk writes. No Roblox Studio writes. Status **disconnected**. Do not continue to step 8.
   - **Disk wins:** `POST /v1/bootstrap/apply` `{ "direction": "disk-to-studio" }` (MUST NOT send `nodes`). Plugin applies the returned `nodes` to mapped Roblox Studio roots (create/update/delete mapped nodes only) and stores each node’s `revision` ([§7.1](07.1-http-api.md#post-v1bootstrapapply)). Continue at step 8.
   - **Roblox Studio wins:** `POST /v1/bootstrap/apply` `{ "direction": "studio-to-disk", "nodes": [ /* the same snapshot submitted at step 5 */ ] }`. Plugin stores the returned `applied` revisions. Plugin MUST NOT mutate the DataModel for this batch. Continue at step 8.
8. Live: plugin opens the event stream (SSE) or starts polling, then listens for Roblox Studio–side mutations on mapped instances. Status **connected**.

## Reading and writing source

| Script tab state | Read | Write |
|------------------|------|-------|
| Open | `ScriptEditorService:GetEditorSource` | `ScriptEditorService:UpdateSourceAsync` |
| Closed | `LuaSourceContainer.Source` | assign `Source` |

This follows official Script / ScriptEditorService guidance ([references.md](../../references.md)).

## Creating and deleting instances

- `upsert` of a new `nodeId`: create missing `Folder` ancestors under the mapped service, then create `Script` / `LocalScript` / `ModuleScript` with the mapped class.
- `delete`: `Destroy()` the instance if it is mapped; MUST NOT destroy unmapped siblings.
- `rename`: set `Name` and/or reparent so the mapped studio path matches; if class must change, destroy and recreate.

Unmapped instances under a mapped root (for example a `Part`) MUST be left untouched (N2).

## Roblox Studio change detection

The plugin MUST observe mapped trees for:

- descendant added/removed
- `Name` changes
- source changes (editor document change or `Source` if closed)

It batches for 50 ms then `POST /v1/apply` with `baseRevision` per node.

## HTTP

Use `HttpService:RequestAsync` for request/response and `HttpService:CreateWebStreamClient` (`Enum.WebStreamClientType.SSE`) for `/v1/events`. Token goes in the query string, not a custom header. The host MUST connect `WebStreamClient.MessageReceived` and apply each `event: change` payload to mapped instances (same `applyDiskEvent` path as poll fallback).

## Error handling

| Condition | Behavior |
|-----------|----------|
| Network / pcall failure | Status “disconnected”; user can reconnect |
| Compare `equal: false` (awaiting bootstrap) | Status “choose Disk wins, Roblox Studio wins, or Cancel” |
| Live | Status “connected” |
| Cancel (unequal bootstrap) | Status “disconnected”; no writes |
| Stream `SESSION_REPLACED` | Status “replaced by another session”; stop applying |
| `CONFLICT` | Widget per-node Disk vs Roblox Studio; no silent overwrite |
| Attempt to bind or scan outside mapped roots | Ignore |

The plugin MUST wrap HttpService calls in `pcall`.

Expected tests: connect-flow state machine with a mock HTTP layer covering `equal: true`, Disk wins, Roblox Studio wins (same snapshot resent as `nodes`), and Cancel (no apply, no live). Studio host tests cover `CreateToolbar("rbx-sync")`, a dockable widget with Connect / Disconnect / bootstrap / conflict choices, a light status-label `TextColor3` on the dark widget, HttpService `RequestAsync` / `CreateWebStreamClient` (pcall-wrapped), Keep-disk / Keep Roblox Studio actions, and a heartbeat that flushes the 50 ms mutation batch. The packaged `.rbxmx` Script entry must start that host with the `plugin` global and sibling `session` / `studio` ModuleScripts. DataModel adapter tests cover create/update/delete of mapped instances, creating missing nested `studio` Folders on disk-to-studio apply, ScriptEditorService for open tabs, and listener-emitted mutations.
