# 6.2 sync-agent

> **Spec chapter:** IDE-independent CLI/daemon that owns the filesystem.
> **Parent:** [6. Components](06-components.md)
> **Index:** [README.md](../README.md)

**Package:** `sync-agent/`  
**File:** `cmd/rbx-sync/main.go` (entry) plus `internal/*`

rbx-sync is the only process that reads or writes the user’s project. It MUST run as a user-level process on Windows or Linux (including WSL) with no Roblox Studio install required for unit tests. Release binaries and one-command install are specified in [§4](04-stack.md) and [§10.1](10.1-install.md).

## Construction / configuration

| Parameter | Default | Notes |
|-----------|---------|-------|
| Project file | `./rbx-sync.json` | Resolved from `--project` directory |
| Bind host | `127.0.0.1` | MUST reject hosts other than `127.0.0.1` and `::1` |
| Port | `29850` | `--port`; MUST be in `1024–65535` excluding `1194` |
| Access token | random 32 bytes hex | Printed once on stderr at serve start |
| Watch debounce | `50ms` | Coalesce filesystem events |

## Commands

Implemented by [§7.3](07.3-cli.md). Serve behavior:

1. Load and validate `rbx-sync.json` against protocol schema. On failure: stderr + exit 1, code `PROJECT_INVALID`.
2. Bind TCP `host:port`. On bind failure: stderr + exit 1.
3. Print `listening`, `protocolVersion`, port, and `accessToken` to stderr.
4. Watch mapped disk roots. Translate events to protocol changes.
5. Serve HTTP ([§7.1](07.1-http-api.md)).
6. SIGINT / Ctrl+C: close streams with a final event, unbind, exit 0.

## Apply from Roblox Studio

`POST /v1/apply` MUST write files using [§6.4](06.4-project-mapping.md):

- `upsert` — create/overwrite file, set contents UTF-8 LF
- `delete` — remove file; remove empty mapped directories that are not a disk root
- `rename` — `os.Rename` when source and dest are on the same root; otherwise copy+delete

Writes MUST be atomic where the OS allows (write temp file + rename in the destination directory).

## Watch to Roblox Studio

After debounce, rbx-sync emits events on `/v1/events` and stores them for `/v1/changes?since=`. Cursor is a monotonically increasing integer starting at 0.

rbx-sync MUST ignore its own writes for echo suppression ([§6.5](06.5-sync-session.md)).

## Plugin install helper

`rbx-sync plugin install` copies the packaged `rbx-sync.rbxmx` (see [§7.3](07.3-cli.md) `--file` default) to the Roblox Studio local plugins folder.

**Destination resolution:**

1. **Windows process:** `%LOCALAPPDATA%\Roblox\Plugins\rbx-sync.rbxmx`.
2. **Linux/WSL:** If `cmd.exe` is available, take `echo %LOCALAPPDATA%` from that Windows user, convert with `wslpath -u`, and append `/Roblox/Plugins/rbx-sync.rbxmx`.
3. If step 2 fails: if exactly one path matching `/mnt/c/Users/*/AppData/Local/Roblox/Plugins` exists, use that directory.
4. Otherwise print the expected Windows path (`%LOCALAPPDATA%\Roblox\Plugins`) and exit 1.

Do not hard-code a Windows username in source or install scripts.

## Error handling

| Condition | Behavior |
|-----------|----------|
| Unknown CLI command | stderr, exit 2 |
| Serve config invalid | stderr, exit 1 |
| HTTP handler error | JSON error envelope + status from [§6.1](06.1-sync-protocol.md) |
| Watcher error | log stderr; keep HTTP up; surface `IO_ERROR` on snapshot/apply if roots unreadable |
