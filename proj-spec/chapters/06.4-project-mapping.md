# 6.4 Project mapping

> **Spec chapter:** How disk paths correspond to Roblox Studio instances.
> **Parent:** [6. Components](06-components.md)
> **Index:** [README.md](../README.md)

**Files:** project `rbx-sync.json`; fixtures `sync-protocol/fixtures/v1/mapping/`

Both rbx-sync and the plugin MUST implement these tables. Fixtures in `sync-protocol` are the conformance suite.

## Project file

Path: `<projectDir>/rbx-sync.json`.

```json
{
  "protocolVersion": 1,
  "name": "example",
  "roots": [
    { "id": "server", "disk": "src/server", "studio": "ServerScriptService" },
    { "id": "client", "disk": "src/client", "studio": "StarterPlayer.StarterPlayerScripts" },
    { "id": "shared", "disk": "src/shared", "studio": "ReplicatedStorage.Shared" }
  ]
}
```

| Field | Rule |
|-------|------|
| `protocolVersion` | MUST equal `1` for this spec |
| `name` | Non-empty string; informational |
| `roots` | Non-empty array |
| `roots[].id` | Unique within the file; `[A-Za-z][A-Za-z0-9_]*` |
| `roots[].disk` | Relative to project dir; POSIX separators in the file; no `..` segments |
| `roots[].studio` | Dot-separated instance path from DataModel `game` (Roblox Studio). First segment MUST be a service name (for example `ServerScriptService`). MUST NOT be `game` alone. |

rbx-sync resolves `disk` against the project directory. WSL and Windows path separators are accepted on the OS when reading, but `rbx-sync.json` always uses `/`.

Duplicate `studio` targets or overlapping `disk` directories MUST fail `PROJECT_INVALID`.

## What is synced

| Disk | Roblox Studio |
|------|---------------|
| Directory without an `init.*` source file | `Folder` with `Name` = directory name |
| Source file (table below) | `LuaSourceContainer` subclass |
| Anything else | Ignored (not deleted, not created) |

v1 does **not** sync Parts, attributes, tags, or other classes (N2). Unmapped children under a Roblox Studio root remain.

## Source file names

Extensions `.luau` and `.lua` are equivalent. If both `Foo.luau` and `Foo.lua` exist in the same directory, `PROJECT_INVALID` (rbx-sync) / refuse apply (plugin).

| File name | Instance `Name` | Class |
|-----------|-----------------|-------|
| `Foo.luau` / `Foo.lua` | `Foo` | `ModuleScript` |
| `Foo.server.luau` / `Foo.server.lua` | `Foo` | `Script` |
| `Foo.client.luau` / `Foo.client.lua` | `Foo` | `LocalScript` |
| `init.luau` / `init.lua` | parent directory name | `ModuleScript` |
| `init.server.luau` / `init.server.lua` | parent directory name | `Script` |
| `init.client.luau` / `init.client.lua` | parent directory name | `LocalScript` |

A directory MUST contain at most one `init.*` source file. Sibling files become children of that init instance, not of a Folder.

A directory with **no** init file is a `Folder`. Source files inside it become children of that Folder.

`init.server.luau` is a **Script** whose `Name` is the parent directory, not a ModuleScript named `init.server`. `init.luau` is the only init **ModuleScript** form.

Forbidden file stems: empty, `.`, `..`, names containing `/` or `\`, or the characters `:*?"<>|`.

## nodeId

`nodeId` is `rootId` + `/` + relative path using `/`, without a leading slash. The relative path uses **instance names**, not raw filenames.

Examples (`id` = `server`, disk `src/server`):

| Disk path | nodeId | Class |
|-----------|--------|-------|
| `src/server/Foo.server.luau` | `server/Foo` | Script |
| `src/server/Util.luau` | `server/Util` | ModuleScript |
| `src/server/Bar/init.luau` | `server/Bar` | ModuleScript |
| `src/server/Bar/Child.luau` | `server/Bar/Child` | ModuleScript |
| `src/server/Qux/` (no init) | `server/Qux` | Folder |

Roblox Studio path `ServerScriptService.Bar.Child` corresponds to `server/Bar/Child` when the root `studio` field is `ServerScriptService`.

## Roblox Studio path resolution

The plugin resolves `studio` by splitting on `.` and walking from `game`. Missing intermediate instances:

- During **disk-to-studio** bootstrap or live create: create `Folder` for missing intermediates except the last node, which uses the mapped class. Missing segments of the mapped `studio` path itself (for example `RbxSyncL5` in `ServerScriptService.RbxSyncL5`) are created as `Folder` under the existing service. A snapshot-time unresolved path (`resolveRoot` false) MUST NOT skip that create.
- During **studio-to-disk** snapshot: skip roots whose path cannot be resolved; surface a plugin warning; do not invent disk files for missing services.

## Line endings and encoding

Disk files MUST be UTF-8. rbx-sync writes LF. If a Roblox Studio source contains CRLF, rbx-sync converts to LF on write. BOM is stripped on read and not written.

Maximum source size: **1 MiB** decoded bytes. Larger ⇒ `PAYLOAD_TOO_LARGE`.

## Inverse mapping (Roblox Studio → disk)

Given `nodeId` and class:

| Class | File relative to disk root |
|-------|----------------------------|
| `ModuleScript` with no mapped children | `Name.luau` |
| `Script` with no mapped children | `Name.server.luau` |
| `LocalScript` with no mapped children | `Name.client.luau` |
| Any of the three with mapped children | directory `Name/` plus the matching `init*.luau` |
| `Folder` | directory `Name/` without init |

Prefer `.luau` on create. If an existing file uses `.lua`, keep that extension on update.
