# 7.3 CLI

> **Spec chapter:** `rbx-sync` user-facing commands.
> **Parent:** [7. External API](07-external-api.md)
> **Index:** [README.md](../README.md)

**Binary:** `rbx-sync` (`rbx-sync.exe` on Windows)

## Commands

| Command | Behavior | Exit 0 |
|---------|----------|--------|
| `rbx-sync serve` | Load project, bind, print token, block | After clean shutdown |
| `rbx-sync plugin install` | Copy plugin artifact to Roblox Studio local plugins folder | When the file is written |
| `rbx-sync version` | Print `agent=<semver> protocol=<n>` to stdout (`agent=` is the rbx-sync binary semver; the key name is a CLI identifier, not the actor table) | Always if binary runs |
| `rbx-sync help` | Usage to stdout | Always |

Unknown command: stderr, exit 2.

## `serve` flags

| Flag | Default | Notes |
|------|---------|-------|
| `--project` | `.` | Directory containing `rbx-sync.json` |
| `--port` | `29850` | See [§6.2](06.2-sync-agent.md) |
| `--bind` | `127.0.0.1` | Only `127.0.0.1` or `::1` |

Stderr MUST include lines containing:

- `protocolVersion=1`
- `listen=127.0.0.1:29850` (actual host:port)
- `accessToken=` followed by the 64 hex chars

so a human (or a future wrapper) can copy the token without scraping JSON.

## `plugin install` flags

| Flag | Default | Notes |
|------|---------|-------|
| `--file` | first existing of: (1) `rbx-sync.rbxmx` in the directory that contains the `rbx-sync` binary; (2) `$HOME/.local/share/rbx-sync/rbx-sync.rbxmx` on Linux/WSL | Override path to `.rbxmx` |

## Error handling

| Condition | Exit | stderr |
|-----------|------|--------|
| Missing `rbx-sync.json` | 1 | `PROJECT_INVALID` message |
| Bind in use | 1 | address in use |
| Invalid `--bind` | 1 | must be loopback |
| Plugin dest missing | 1 | print expected Windows/WSL path |
