# 7.1 HTTP API

> **Spec chapter:** Request/response routes on rbx-sync.
> **Parent:** [7. External API](07-external-api.md)
> **Index:** [README.md](../README.md)

**Base:** `http://127.0.0.1:29850` (default)  
**Auth:** `?accessToken=` on all routes except health ([§6.1](06.1-sync-protocol.md)).

All JSON request bodies MUST match `sync-protocol` HTTP schema. Unknown fields MUST be ignored (forward compatible) except inside `error`.

## Routes

| Method | Path | Auth | Success |
|--------|------|------|---------|
| GET | `/v1/health` | no | 200 `{ "ok": true, "protocolVersion": 1 }` |
| POST | `/v1/session` | yes | 200 session snapshot metadata |
| POST | `/v1/bootstrap/compare` | yes | 200 `{ "equal": bool }` |
| POST | `/v1/bootstrap/apply` | yes | 200; body depends on `direction` (see below) |
| GET | `/v1/snapshot` | yes | 200 `{ "nodes": [...] }` |
| POST | `/v1/apply` | yes | 200 `{ "applied": [...] }` |
| GET | `/v1/events` | yes | 200 SSE ([§7.2](07.2-event-stream.md)) |
| GET | `/v1/changes` | yes | 200 `{ "cursor": n, "changes": [...] }` |

Unlisted paths: HTTP **404** with envelope `error.code` **`NOT_FOUND`** (message “not found”). Do not use `BAD_REQUEST` for unlisted paths.

## POST /v1/session

Request:

```json
{
  "protocolVersion": 1,
  "pluginVersion": "0.0.0"
}
```

| Field | Required | Notes |
|-------|----------|-------|
| `protocolVersion` | yes | MUST match rbx-sync or `PROTOCOL_MISMATCH` |
| `pluginVersion` | yes | Informational semver string |

Success:

```json
{
  "protocolVersion": 1,
  "agentVersion": "0.0.0",
  "projectName": "example",
  "roots": [{ "id": "server", "studio": "ServerScriptService" }]
}
```

Does not include disk paths (Roblox Studio does not need them). Replaces any existing session.

## POST /v1/bootstrap/compare

Request: `{ "nodes": [ /* Roblox Studio snapshot, Node array */ ] }`  
Success: `{ "equal": true }` or `{ "equal": false }`.  
Comparison is by `nodeId`, `className`, and source bytes after LF normalization. Folders compare without source.

## POST /v1/bootstrap/apply

Request:

```json
{
  "direction": "disk-to-studio"
}
```

or

```json
{
  "direction": "studio-to-disk",
  "nodes": [ ]
}
```

| `direction` | Request `nodes` | Success body |
|-------------|------------------|--------------|
| `disk-to-studio` | omitted (MUST NOT send `nodes`) | `{ "nodes": [ /* disk Node array, each with revision */ ] }` — same Node shape as `GET /v1/snapshot`. Plugin MUST apply this set to mapped Roblox Studio roots. |
| `studio-to-disk` | required | `{ "applied": [ { "nodeId": "…", "revision": 1 } ] }` after disk writes. Fresh serve: every remaining mapped node is revision **1**. |

Cancel is a plugin-only action (no HTTP). Mixing `direction` and the wrong body fields is `BAD_REQUEST`.

## GET /v1/snapshot

Disk-side mapped nodes after bootstrap or during live. Same `nodes` array shape as [§8](08-domain-model.md).

## POST /v1/apply

Request:

```json
{
  "changes": [
    {
      "op": "upsert",
      "nodeId": "server/Foo",
      "className": "Script",
      "source": "print('hi')\n",
      "baseRevision": 3,
      "force": false
    }
  ]
}
```

| `op` | Required fields |
|------|-----------------|
| `upsert` | `nodeId`, `className`, `source` (empty string allowed), `baseRevision` |
| `delete` | `nodeId`, `baseRevision` |
| `rename` | `nodeId`, `newNodeId`, `baseRevision` |

`className` for `upsert` MUST be `Script`, `LocalScript`, `ModuleScript`, or `Folder`. `source` MUST be omitted for `Folder` (if present: `BAD_REQUEST`).

Success: `{ "applied": [ { "nodeId": "server/Foo", "revision": 4 } ] }`. Rename ack uses `newNodeId`.

Partial conflict: HTTP 409, envelope `CONFLICT`, plus `applied` for succeeded entries and `conflicts: [{ "nodeId", "currentRevision" }]`.

## GET /v1/changes

Query: `since` (integer cursor, default 0).  
Success: `{ "cursor": <new>, "changes": [ /* Event */ ] }` in cursor order. Does not block. Empty `changes` if none.

## Error handling

Statuses follow [§6.1](06.1-sync-protocol.md). Invalid JSON: 400 `BAD_REQUEST`.
